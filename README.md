# 🧮 JavaScript Calculator

A simple and interactive calculator built using **HTML, CSS, and JavaScript**. This project performs basic arithmetic operations with a clean user interface and interactive buttons.

## 🚀 Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Supports multiple-digit calculations
- Clear button to reset the display
- Interactive buttons
- Real-time input display

## 🛠️ Technologies Used

- **HTML5** – Structure of the calculator.
- **CSS3** – Styling and layout.
- **JavaScript** – Functionality and calculation logic.

   ```bash

   ```

3. Open `index.html` in your browser.
4. Start performing calculations!
